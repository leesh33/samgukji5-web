16비트 레트로 감성의 **도트 웹 전략 게임**. 삼국 시대를 배경으로 설치 없이 브라우저에서 바로 하며, 모바일(390×844) 세로 화면에 맞춰 만들었습니다.

- 실서버: https://samgukji5-web.vercel.app (Vercel · 정적 배포)
- 저장소: https://github.com/leesh33/samgukji5-web

## 조작

- **지도**: 드래그 이동 · 핀치/휠 확대 · 탭으로 성 선택 · 지도 위 `권역` 버튼으로 빠른 이동 · 우하단 ＋/－
- **상단 자원 바**: `세력` 표시 아래 금 · 식량 · 총병력 · 명성 · 행동력 (세력 전체 자원. 성별 보유량은 성 시트에 따로 표시)
- **성 시트**: 성을 탭하면 하단에 **펼쳐진 채로** 붙습니다(정보·장수·명령). `접기`로 요약 줄만 남기고, `✕`로 닫으면 지도가 화면을 꽉 채웁니다. 성을 새로 탭하면 다시 펼쳐집니다
- **성 넘기기**: 하단 시트를 **좌우로 스와이프**하면 내 성끼리 넘어가고 지도도 그 성으로 이동합니다. 헤더의 `‹ 1/3 ›` 표시로 현재 순서를 보거나 눌러서 넘길 수도 있습니다(장수 초상화 줄 위에서는 초상화 스크롤이 우선)
- **전투**: 아군 부대 탭 → 이동/공격/계략/일기토/대기, `전군 돌격`으로 전 부대 자동 지휘, `진행`으로 적 턴
- **소리**: 우상단 ♪ 버튼으로 8/16비트 효과음 On/Off (설정은 브라우저에 저장)

## 신군주로 시작하기

시나리오 선택 화면 맨 위 `★ 신군주 생성`(또는 군주 선택 화면 맨 아래 `★ 이 시나리오에서 신군주로 시작`)을 누르면 새 세력을 만들 수 있습니다.

1. **시나리오** — 7종 중 하나를 고릅니다(기본 184 황건의 난).
2. **군주 이름·깃발 한자** — 2~6자 이름과 깃발에 새길 한자 1자를 정합니다(프리셋 10자 또는 직접 입력).
3. **세력 색·초상화** — 8색 팔레트와 머리(투구·관모·두건·상투·전립)·수염(4종)·피부(4종) 프리셋으로 도트 초상화를 만듭니다(실시간 미리보기).
4. **능력치** — 통솔·무력·지력·정치·매력에 총 225점을 나눠 넣습니다(항목당 20~96). `🎲 주사위로 다시 굴리기`로 한 번에 무작위 배분할 수 있습니다.
5. **특기·주력 병과·시작 성** — 특기 8종, 병과 4종, 그리고 성이 둘 이상인 세력에서 떼어낼 성 하나를 고릅니다(그 세력은 나머지 성을 지킵니다).
6. **휘하 장수** — 혼자 시작하거나 신무장 1~2명(한석·위담)을 데리고 시작합니다.

만든 세력과 신무장은 저장 파일(자동 저장·슬롯 1~3·클라우드)에 함께 들어가 이어하기로 그대로 복원됩니다.

## 개발

정적 파일만으로 동작합니다(빌드 없음, ES Module).

```bash

node --test 'tests/*.test.js'     # 엔진·전투·일기토·데이터·신군주·클라우드 동기화 테스트 49개
python3 tests/verify_live.py http://127.0.0.1:4173/index.html local   # Playwright 390×844 검증
python3 tests/verify_sheet.py http://127.0.0.1:4173/index.html local  # 하단 시트 펼침·스와이프 도시 전환 검증
python3 tests/verify_custom.py http://127.0.0.1:4173/index.html local  # 시나리오 7종·신군주 생성/전투/저장·복원 검증
python3 tests/verify_cloud.py http://127.0.0.1:4173/index.html        # 로그인 버튼·메뉴 자리 확인
```

### ☁ 로그인 · 클라우드 저장

로그인은 **선택**입니다. 비로그인 상태에서는 기존처럼 localStorage 에만 저장되고, 로그인하면 자동 저장과 슬롯 1~3이 `public.samguk_saves` 로 합쳐집니다.

- 화면: 타이틀 화면 버튼 아래, 게임 내 `≡` → 군의(軍議) 맨 위
- 로그인: Supabase GoTrue OAuth(PKCE) — Google · 카카오 (`js/sync.js`)
- 합치기: 슬롯마다 마지막 저장 시각이 최신인 쪽(같으면 더 진행된 쪽), 한쪽에만 있는 슬롯은 지우지 않음 (`js/sync-core.js`)
- DB: `supabase/samguk_cloud_sync.sql` — RLS(본인 행만) + RPC `samguk_put_saves`(과거 revised_at 무시)
- 공용 프로젝트 `zdcdvjlssncsawpqsjwe` (릴스핀·인생 한 턴과 같은 프로젝트, 테이블·함수 이름은 `samguk_` 접두사로 분리)

## 참고

- 독자 제작 게임입니다. 외부 게임의 이미지·사운드·데이터를 사용하지 않았고, 지도·초상화·아이콘은 모두 코드로 그린 도트 그래픽입니다.
- 장수 능력치와 시나리오 소속은 삼국 시대 고전 전략게임의 통념을 참고한 게임용 근사치입니다.
