- **계략**: 성 시트의 `계략`(내 성에서) 또는 적 성 시트의 `계략` — 대상 성·계략 종류·파견 장수를 고르면 예상 성공률과 함께 실행됩니다

- **포상 실제 상승분 표기**: 충성 85인 장수를 포상하면 연출·군보·로그 모두 `충성 +15`(85 → 100)로 적습니다. 100 캡이 걸리는 다른 수치도 같이 맞췄습니다 — 훈련(98 → +2)·장군 임명 충성·대회 하사 충성·개발·상업·치안·수리. 충성이 이미 100인 장수에게는 금 120을 쓰지 않고 `이미 최대(100)`이라고 알립니다.
- **부대 편성 일괄 버튼 위치**: `균등 편성`·`상한 채우기`·`모두 해제`를 장수 목록 **아래에서 요약 바 바로 아래**로 올려, 목록을 스크롤하지 않고 누를 수 있게 했습니다(390×844에서 겹침·잘림 0).
- **검증**: `tests/verify_cap_display.py` — 치안 `/100` 표시·100 상한·포상 `+15` 연출·군보·부대 편성 버튼 위치를 라이브로 확인합니다.


## v13에서 더해진 것 — 부대 편성(병사 재편 · 병종 변경)

- **병사 재편**: 성 총병력 = 장수별 편성 병력 + 예비병. `군사` → `부대 편성`에서 장수마다 병력을 미리 나눠 맡깁니다(예: 하후돈 3,000 · 조인 2,000 · 나머지 예비병). 슬라이더와 `-500 / +500 / 최대 / 비우기`, 한 번에 나누는 `균등 편성`·`상한 채우기`·`모두 해제`. 지휘 상한 안에서만 맡길 수 있고 합계는 성 총병력을 넘지 않습니다. **행동력 0 — 언제든 다시 나눌 수 있습니다.**
- **병종 변경**: 장수마다 보병 · 기병 · 궁병으로 바꿉니다(원래 병과가 수군이면 수군으로 되돌릴 수 있습니다). **금 100**, 행동력 0. 장수 상세·성 시트 칩·전투에 바뀐 병종이 그대로 나옵니다.
- **출진 연동**: 편성된 병력이 있으면 그 병력으로 출진합니다(편성이 없으면 기존 자동 배분). 출진과 동시에 성 총병력에서 그만큼 빠지고, 이기면 생존 병력이 함락한 성에 들어가며, 지면 살아 돌아온 병력이 성의 예비병으로 돌아옵니다. 장수가 성을 옮기거나 포로·전사하면 맡긴 병력은 원래 성의 예비병으로 돌아갑니다.
- **표시**: 성 시트 장수 칩(병종 + 편성 병력), 장수 상세(병종·원래 병과·편성 병력·예비병), 출진 시트(장수별 출진 병력).

## v12에서 더해진 것 — 성 규모(소형·중형·대형·특대형)

- **성 규모**: 42성 모두에 소형·중형·대형·특대형이 붙었습니다. 낙양·장안·업·성도·건업은 대형, 허창·수춘·강릉·양양·계·진양·남피·임치·하비·진류·강하·장사·오·한중은 중형, 나머지 23성은 소형에서 시작합니다.
- **승격**: 농업·상업·수리를 그 규모의 상한까지, 치안을 100까지 채우면 소형 → 중형 → 대형 → 특대형으로 저절로 오릅니다. 상한이 100 → 130 → 160 → 200으로 넓어지는 방식이라, 채운 수치가 깎여 다시 채우는 일은 없습니다. 승격하면 군보에 `[규모 승격]` 기록과 축하 안내가 뜨고, 지도 노드도 그만큼 커집니다.
- **규모의 힘**: 징병 ×1.0 · ×1.25 · ×1.5 · ×1.8, 금·식량 세입 +0·8·16·25%, 주둔 병력 맥스 30,000 · 50,000 · 100,000 · 200,000.
- **주둔 상한 = min(규모 맥스, 인구 × 30%)**: 성마다 인구가 있고, 인구는 농업·상업·수리·치안을 올리면 수용력까지 달마다 자랍니다(월 0.3~0.8%). 인구가 늘면 병력 상한도 따라 오르고, 함락·역병으로 주민이 흩어지면 내려갑니다. 출진 예상의 시트 병력 칸이 `병력 / 최대치`입니다.
- **지휘 상한**: 일반 7,500 → 대장군 25,000명(군주 25,000). 병사 급료는 90명당 금 1, 군량은 45명당 1 — 대형 성을 10만까지 채우면 달마다 금 ~1,100 · 식량 ~2,200이 들어, 꽉 닦은 대형 성 세입(금 ~1,020 · 식량 ~1,580)과 맞먹습니다.
- **표시**: 지도 노드 크기, 성 시트 헤더 배지(`예주 | 허창 | 중형 | 조조`)와 내정 칸의 수치별 상한(`/130` · 치안 `/100`), 정보 › 아군 도시 배지.
- **저장**: `SAVE_VERSION 11` — 옛 저장(v3~v10)은 도시별 역사적 기본 규모를 채워 이어집니다.

### 📊 접속자 통계 · 어드민 (`/admin.html`)

- 화면·데이터의 모든 표기는 한글입니다(한자 표기 없음). 깃발·배지도 한글 1자입니다.
- 장수 능력치와 시나리오 소속은 삼국 시대 고전 전략게임의 통념을 참고한 게임용 근사치입니다.

## 📱 iOS 앱 (App Store · `com.odol.dotsamguk`)

`../samguk-app`(Expo SDK 51 + WebView)이 이 웹앱을 iOS 앱으로 감쌉니다. 앱은 **라이브 주소**(https://dotsamguk.vercel.app)를 그대로 띄우고, 네트워크가 없거나 페이지가 뜨지 않으면 앱에 내장한 한 파일 HTML 로 **오프라인 플레이**를 고를 수 있습니다.

| 문제 | 이 웹앱의 답 |
| --- | --- |
| Apple 로그인(iOS 앱) | 앱이 네이티브 Sign in with Apple 로 `id_token` 을 받아 `window.SamgukNative.appleSignIn(idToken, nonce)` 로 넘깁니다. 페이지는 Supabase `grant_type=id_token` 으로 세션을 만듭니다(Supabase Apple provider Client IDs 에 `com.odol.dotsamguk` 포함). Apple 칩은 **앱 안에서만** 보입니다 — 웹은 지금처럼 Google·카카오 그대로입니다. |
| Google·카카오 로그인(iOS 앱) | 페이지가 authorize 주소를 앱에 넘기면(`postMessage {type:'oauth'}`) 앱이 `ASWebAuthenticationSession` 으로 열고, `samguk://auth-callback?code=…` 로 돌아온 주소를 `window.SamgukNative.oauthCallback(url)` 로 넘깁니다 → 페이지의 PKCE verifier 로 교환. |
| 앱 다리 | 앱이 `window.__SAMGUK_NATIVE__ = { shell:'ios', appleAuth:true, appVersion }` 를 심습니다. 없으면 웹 방식(페이지 이동) 그대로입니다. |
| 계정 삭제 (App Store 5.1.1(v)) | 로그인 후 `☰` 군의 → **계정 · 클라우드 기록 삭제** — 2단계 확인 뒤 Supabase RPC `samguk_delete_my_account()` 로 본인 기록을 지웁니다. 같은 계정을 쓰는 다른 앱(릴스핀·인생 한 턴) 기록이 있으면 계정은 남기고 이 게임 기록만 지웁니다(`supabase/samguk_account_delete.sql`). |
| 약관 웹 페이지 | `privacy.html` · `terms.html` — 앱 안 모달과 **같은 문구**(`js/legal.js`)를 그립니다. App Store 메타데이터의 개인정보처리방침 URL 로 씁니다. |
