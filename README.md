# 삼국지 오 · 천하대세 (Samgukji 5 Web)

삼국지 V(KOEI) 감성의 **레트로 도트 웹 전략 게임**. 설치 없이 브라우저에서 바로 하며, 모바일(390×844) 세로 화면에 맞춰 만들었습니다.

- 실서버: https://samgukji5-web.vercel.app (Vercel · 정적 배포)
- 저장소: https://github.com/leesh33/samgukji5-web

## 무엇을 할 수 있나

| 항목 | 내용 |

| 군주 | 시나리오별 8~18세력 중 선택 (조조·유비·손권·여포·원소·유표·유장·마등 등) |
| 성 | 전국 42성 (유주~교주 13권역, 낙양·장안·허창·업·건업·강릉·양양·한중·성도 등) + 도로망 |
| 장수 | 실존 장수 167명 (통솔·무력·지력·정치·매력·병과·특기·보유진형) |
| 내정 | 개발·상업·치안·수리·징병·훈련·탐색·등용·포상·수송 (월별 턴 · 명성 · 행동력) |

| 진형 | 어린·학익·봉시·방원·언월·장사·안행·구행·수진 9종 (공격/방어/기동/사거리 차이) |

| AI 군주 | 매월 내정·징병·등용 후 인접 약소 성을 실제로 공격 |
| 저장 | localStorage 자동 저장 + 수동 슬롯 3개, 천하통일/멸망 엔딩 |

## 조작

- **지도**: 드래그 이동 · 핀치/휠 확대 · 탭으로 성 선택 · 상단 권역 칩으로 빠른 이동 · 우하단 ＋/－
- **성 패널**: 선택한 성의 내정 수치와 장수, 명령 버튼. 적 성은 인접 아군 성에서 공격
- **전투**: 아군 부대 탭 → 이동/공격/계략/일기토/대기, `전군 돌격`으로 전 부대 자동 지휘, `진행`으로 적 턴
- **소리**: 우상단 ♪ 버튼으로 8/16비트 효과음 On/Off (설정은 브라우저에 저장)

## 개발

정적 파일만으로 동작합니다(빌드 없음, ES Module).

```bash
python3 -m http.server 4173      # http://127.0.0.1:4173
node --test 'tests/*.test.js'     # 엔진·전투·일기토·데이터 무결성 테스트 26개
python3 tests/verify_live.py http://127.0.0.1:4173/index.html local   # Playwright 390×844 검증
```

## 참고

- 팬메이드 게임입니다. KOEI의 이미지·사운드·데이터를 사용하지 않았고, 지도·초상화·아이콘은 모두 코드로 그린 도트 그래픽입니다.
- 장수 능력치와 시나리오 소속은 고전 삼국지 게임의 통념을 참고한 게임용 근사치입니다.
